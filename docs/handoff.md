# Handoff

The bundled core displays the Vendo name on the banner and uses “No vendo” when no name is available. Direct-file startup uses local scripts, and cached user information keeps the portal disconnected until a live response confirms the session. Storage failures preserve the current Vendo selection for the page. The QR image and game wheel fit narrow screens using width and max-width.

Run the regression command in the README. Unit tests simulate browser restrictions and router template substitution. Physical captive-browser checks on the oldest target devices remain pending.
